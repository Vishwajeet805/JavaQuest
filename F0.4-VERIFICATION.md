## Verification blocked by sandbox networking

The execution environment cannot reach `registry.npmjs.org`, and pnpm is not preinstalled. Therefore a real dependency install, lockfile generation, lint, typecheck, Vitest run, Next build, and tsup build could not be executed here.

On the first networked machine, run:

```bash
pnpm install
cp .env.example .env
docker compose -f infra/docker/docker-compose.yml up -d
pnpm db:generate
pnpm db:push
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

Then commit the generated `pnpm-lock.yaml` and switch CI's install command back to `pnpm install --frozen-lockfile`.
